# Cahier Major Studio React

Application React/Vite pour composer des cahiers A5 :

- pages multiples ;
- blocs de cours/exercices/tableaux/redaction ;
- drag/drop ;
- resize par poignee ;
- styles de blocs ;
- themes de page ;
- export/import JSON ;
- impression A5.

## Lancer

Depuis le dossier parent, double-cliquer :

```bat
lancer-cahier-studio-react.cmd
```

Puis ouvrir :

```text
http://127.0.0.1:5173
```

La fenetre de commande doit rester ouverte.

## Rebuild apres modification

```bat
cd cahier-studio-react
npm.cmd run build
```
