القاعدة الأساسية
الإعراب هو تغيير آخر الكلمة بسبب موقعها في الجملة. للأسماء ثلاث حالات : الرفع · النصب · الجر. وللفعل المضارع حالة رابعة : الجزم.
الرفع — الضمة ( ُ )
الفاعل · المبتدأ · الخبر
المثنى : ان  |  الجمع : ون
جاءَ الولدُ · المعلمُ كريمٌ
النصب — الفتحة ( َ )
المفعول به · الحال · خبر إنّ
المثنى وجمع المذكر : ين
رأيتُ الولدَ · إنّ العلمَ نور
الجر — الكسرة ( ِ )
بعد حروف الجر : في، على، من…
المضاف إليه
ذهبتُ إلى المدرسةِ
الجزم — السكون ( ْ )
للفعل المضارع فقط
بعد : لم · لمّا · لا الناهية
لم يكتبْ · لا تكذبْ
حيلة الحفظ
تذكّر كلمة « رَنَجَزْ » : الراء للرفع — النون للنصب — الجيم للجر — الزاي للجزم. كلمة واحدة تحفظ لك كل الحالات !

3
