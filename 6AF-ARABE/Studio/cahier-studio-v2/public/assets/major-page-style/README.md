# Kit style page Major

Objectif : rapprocher `Cahier-Major-LangueArabe-Islamique-6AF-V3-Cartoon.html` du style cahier premium montre dans la reference : bordures bleues, spirale, badges, stickers, blocs d'exercices et zones de ressources.

## Assets principaux

- `major-page-mockup-reference.png` : exemple visuel pleine page, a utiliser comme direction artistique, pas forcement comme image finale dans le cahier.
- `spiral-binding.png` : spirale transparente pour le bord droit des pages.
- `school-stickers.png` : planche transparente avec stickers et doodles scolaires.
- `lesson-header-badge.png` : badge de titre vide, le texte doit etre ajoute en HTML.
- `rule-reminder-box.png` : bloc "regle / a retenir" vide, le texte doit etre ajoute en HTML.
- `exercise-cards.png` : cartes d'exercices vides, le contenu doit etre ajoute en HTML.
- `resources-footer.png` : bande ressources numeriques vide, avec emplacement QR blanc.

## Dossier source

Le sous-dossier `source-chromakey/` contient les versions originales sur fond vert utilisees pour creer les PNG transparents.

## Recommandations d'integration

- Garder tout le texte arabe en HTML/CSS pour eviter les lettres deformees dans les images.
- Utiliser les PNG transparents comme decoration superposee ou arriere-plan de bloc.
- Conserver la palette : bleu Major, jaune/or, creme, bleu pale, vert menthe et petites touches rouges.
- Eviter de surcharger chaque page : 1 grand composant + 2 ou 3 stickers suffisent.
